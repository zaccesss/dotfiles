# guides/

Platform setup walkthroughs and the full command reference for each platform. Each guide covers installation, all 35 topic areas with every alias and function described and instructions for adding or removing commands safely.

## Files

| File | Platform | Contents |
| --- | --- | --- |
| [`mac.md`](mac.md) | macOS (zsh) | Installation, full command reference, customisation guide |
| [`linux.md`](linux.md) | Linux and WSL2 (bash) | Installation, full command reference, WSL2 notes |
| [`windows.md`](windows.md) | Windows (PowerShell) | Installation, full command reference, Windows Terminal setup |
| [`new-device.md`](new-device.md) | All platforms | Step-by-step setup guide for a brand new machine |
| [`documentation.md`](documentation.md) | All platforms | Full technical reference: architecture, loader mechanics and every command described |

## When to use these guides

- **First setup** on a new device: start with the platform guide for installation and token setup
- **Looking up a command** in detail: use the platform guide - each alias and function is described with its exact behaviour and any prerequisites
- **Quick scan at the terminal**: run `cmds` to see all commands in grouped format, piped through a pager, press q to exit
