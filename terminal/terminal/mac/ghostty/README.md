Not installed on this machine yet. `config` in this folder is a recommended starter config, not a
real, applied setup. Colours come from the eight Zacess themes, one `zacess-*` file per theme
written by `scripts/build-themes.py`, see [guides/themes.md](../../guides/themes.md). The config

the real config once Ghostty is actually installed and configured.
