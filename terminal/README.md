# terminal

The terminal itself and the tools that run inside it, all in the same high-contrast Zacess themes so
every window reads the same way.

| Folder | What it is | Platforms |
| --- | --- | --- |
| [terminal](terminal) | The eight Zacess colour themes for Terminal.app, iTerm2, Windows Terminal, Ptyxis, GNOME Terminal, Alacritty, Kitty and Hyper, plus starter configs with per-platform fonts | macOS, Linux and Windows |
| [tmux](tmux) | tmux with vi-style copy mode and pane navigation, a plain high-contrast status bar and plugins for session persistence | macOS and Linux |
| [cli-tools](cli-tools) | ripgrep, fzf, lazygit and zoxide defaults with a high-contrast theme and vi-style navigation | macOS, Linux and Windows |
