# nano themes

GNU nano in the eight Zacess themes, so the editor matches the terminal around it.

## What is here

| Path | What it is |
| --- | --- |
| `themes/zacess-<theme>.nanorc` | One nano colour file per Zacess theme, generated by `terminal/terminal/scripts/build-themes.py` from `palette/zacess.json`. Do not edit by hand. |

## How a theme is chosen

`zt` links the current theme's file to `~/.config/nano/zacess-theme.nanorc` on every switch
(`%USERPROFILE%\.config\nano` on Windows, the same path seen from Git Bash), which the `nanorc` in
[`editors/nano`](../../editors/nano/) includes. nano reads its files at start, so an open nano keeps
its colours until it is reopened. Only that link changes, so every other nano setting stays as it
is.

## Colours

Each file sets nano's interface colours (title bar, status line, prompts, key tags, line numbers,
selected text, search matches, the error bar and the scrollbar) in nano's three-digit hex form. nano
shows the nearest colour in the terminal's colour cube, so the generator measures every pair as
shown and holds text to 4.5:1 or more. Syntax highlighting uses nano's own definitions, which name
the terminal's colours and so follow the palette.

The settings, keys, install steps and accessibility notes are in
[`editors/nano`](../../editors/nano/).
