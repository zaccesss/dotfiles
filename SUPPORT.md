# Support

Need help or have a question about any folder in this repository?

- **Questions and ideas.** Open an issue with the [issue forms](https://github.com/zaccesss/dotfiles/issues/new/choose).
- **Something broken?** Use the bug report form. Say which folder, which platform and what happened.
- **Setting up a machine?** Start with the bootstrap README for your platform in [setup](setup/README.md).
- **One tool on its own?** Each folder's README links its setup guide.
- **More about me and my work.** [isaacadjei.me](https://isaacadjei.me).

> [!TIP]
> Reach me directly at support@isaacadjei.me for help. For anything else, use contact@isaacadjei.me or my [contact page](https://isaacadjei.me/contact).

> [!IMPORTANT]
> For a security issue, follow [SECURITY.md](SECURITY.md) rather than posting publicly.
