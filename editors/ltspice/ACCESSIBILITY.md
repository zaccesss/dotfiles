# Accessibility

High contrast schematics and waveforms, so LTspice reads like the other tools.

## Vision

- The default is Zacess Deep Contrast Dark: a black background with parts, wires and labels in its fully saturated syntax colours. All eight Zacess themes are available, light ones included. Measured contrast is in the [Zacess Themes accessibility statement](https://github.com/zacesshq/themes/blob/main/ACCESSIBILITY.md).
- Waveform traces take the theme's terminal colours, chosen to stay distinct from each other and the background.
- The macOS app takes the same colours through its own preferences. It has one schematic colour fewer than Windows, so that one keeps LTspice's default there.
- Each trace is also named in the plot's legend and the cursor readout, so colour is never the only signal.
