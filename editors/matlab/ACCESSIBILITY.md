# Accessibility

A high contrast desktop, matching syntax colours and a clear code font, so MATLAB reads like the other editors.

## Vision

- Code is GeistMono Nerd Font at 14 points (GeistMono Nerd Font Mono at 18 on a Mac's higher density display).
- The default is Zacess Deep Contrast Dark with MATLAB's dark desktop. All eight Zacess themes are available, light ones included. Measured contrast is in the [Zacess Themes accessibility statement](https://github.com/zacesshq/themes/blob/main/ACCESSIBILITY.md).
- The editor takes the theme's own text and background in both MATLAB themes, so code reads the same as in the other editors, with nothing left on MATLAB's default greys.
- Errors and warnings keep distinct hues (red and amber) and MATLAB also marks them with icons and underlines, so colour is never the only signal.
