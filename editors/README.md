# editors

Every editor and IDE I use, set up with the same Zacess themes, Geist Mono and one consistent
`Cmd+Alt` (macOS) or `Ctrl+Alt` (Windows and Linux) pair for custom key bindings.

| Folder | What it is | Platforms |
| --- | --- | --- |
| [vscode](vscode) | Settings, keybindings, global snippets, launch flags, project templates and a curated extension list | macOS, Linux and Windows |
| [zed](zed) | Settings with the Zacess Deep Contrast Dark theme, the theme extensions it needs and a script that installs the Zacess theme file and sets the theme | macOS, Linux and Windows |
| [jetbrains](jetbrains) | Plugin lists per IDE, a small keymap layered on the VS Code keymap and Toolbox settings, applied to every IDE by a script with the Zacess theme plugin | macOS, Linux and Windows |
| [eclipse](eclipse) | Java compiler defaults, autosave, editor basics, 15 VS Code style key bindings and the Zacess themes, merged into a workspace by script | macOS, Linux and Windows |
| [stm32cubeide](stm32cubeide) | The Zacess themes mapped to C, Geist Mono and 15 VS Code style key bindings, merged into a workspace by script | macOS, Linux and Windows |
| [arduino](arduino) | Arduino IDE 2 settings and the Zacess themes from their VS Code package, merged into its settings by script | macOS, Linux and Windows |
| [microchip-studio](microchip-studio) | The Zacess themes converted for Microchip Studio 7 with Geist Mono, imported by script | Windows |
| [kicad](kicad) | The Zacess themes for KiCad's schematic, PCB, GerbView and 3D viewer canvases, installed and picked by script | macOS, Linux and Windows |
| [vivado](vivado) | The Zacess colours for Vivado's text editor and Geist Mono, merged into its settings by script | Linux and Windows |
| [processing](processing) | The Zacess themes for Processing 4 and Geist Mono, written into the sketchbook by script | macOS, Linux and Windows |
| [notepad-plus-plus](notepad-plus-plus) | The Zacess themes for Notepad++ with Geist Mono, used with its dark mode | Windows |
| [nextpad-plus-plus](nextpad-plus-plus) | The Zacess themes for Nextpad++, the macOS port of Notepad++ | macOS |
| [thonny](thonny) | The Zacess themes as a Thonny plugin, Geist Mono and larger text | macOS, Linux and Windows |
| [matlab](matlab) | The Zacess desktop and syntax colours and Geist Mono, set through MATLAB's settings API | macOS, Linux and Windows |
| [ltspice](ltspice) | The Zacess colours for LTspice's schematics, waveforms and netlists | macOS, Linux and Windows |
| [proteus](proteus) | The Zacess colours for Proteus's schematic templates, PCB layout and graphs, with Proteus's own colours one command away | Windows |
| [xcode](xcode) | The eight Zacess themes, the recorded editor settings and the key bindings file, installed by one script | macOS |
| [neovim](neovim) | Pure Lua config with lazy.nvim, LSP through Mason, treesitter, Telescope and completion | macOS, Linux and Windows |
