# Accessibility

A high contrast editor and window, so Notepad++ reads like the other editors.

## Vision

- Editor text is GeistMono NF at 14 points.
- The default is Zacess Deep Contrast Dark with Notepad++'s dark mode, so menus, tabs and dialogs are dark too. All eight Zacess themes are available, light ones included, from **Settings > Style Configurator**. Measured contrast is in the [Zacess Themes accessibility statement](https://github.com/zacesshq/themes/blob/main/ACCESSIBILITY.md).
- Keywords are bold as well as coloured, so colour is never the only signal.
