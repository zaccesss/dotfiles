# Accessibility

Larger text, a high contrast theme across the whole window and a visible current line, so Thonny reads like the other editors.

## Vision

- Editor and shell text are Geist Mono at 16 points, larger than Thonny's default. macOS uses GeistMono Nerd Font Mono, whose icons keep a fixed width.
- The default is Zacess Deep Contrast Dark for both the interface and the code. All eight Zacess themes are available, light ones included, from **Tools > Options > Theme & Font**. Measured contrast is in the [Zacess Themes accessibility statement](https://github.com/zacesshq/themes/blob/main/ACCESSIBILITY.md).
- The current line is highlighted and line numbers are on, so the cursor is easy to find.
- Errors in the shell are also written as text tracebacks, so colour is never the only signal.
