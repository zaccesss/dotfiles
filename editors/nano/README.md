# nano

My nano settings: one `nanorc` for GNU nano on every machine, VS Code's keys where nano can take them and the eight Zacess themes, switched by `zt` like every other editor.

## What it sets

| Setting | Value | Why |
| --- | --- | --- |
| `linenumbers`, `constantshow`, `stateflags` | On | Line numbers, the cursor position on the status line at all times and the mode flags top right, so the place in a file is always on screen |
| `softwrap`, `atblanks` | On | Long lines wrap at a space instead of running off the edge |
| `tabsize`, `tabstospaces`, `autoindent` | 4, on, on | Four spaces, the same as every other editor here |
| `smarthome`, `zap`, `trimblanks` | On | Home goes to the first character, typing over a selection replaces it and trailing spaces go when a line is wrapped |
| `indicator`, `mouse` | On | A scrollbar and mouse clicks for the cursor and the menus |
| `historylog`, `positionlog` | On | Search history and the cursor position come back when a file is reopened |

The file keeps to what nano 6.0 understands, so the packaged nano on any supported Linux (7 or 8 on current Ubuntu and Fedora), Homebrew's and the one inside Git for Windows all read it the same way. nano stops at start on an option it does not know, so nothing newer goes in.

## Keys

| Key | Does | Was |
| --- | --- | --- |
| `Ctrl+S` | Save | Save (nano's own since 4.0) |
| `Ctrl+Q` | Quit, in every menu | Search backwards |
| `Ctrl+Z` | Undo | A hint that `Ctrl+T` then `Ctrl+Z` suspends |
| `Ctrl+Y` | Redo | Page up |
| `Ctrl+F` | Find | Right one character |

nano's own keys stay beside them: `Ctrl+C` shows the cursor position, `Ctrl+X` exits, `Ctrl+O` writes out, `Ctrl+W` searches, `Ctrl+\` replaces and `Ctrl+G` opens the help. `Ctrl+T` then `Ctrl+Z` suspends nano, since `Ctrl+Z` alone is undo here. The bottom two lines list the keys at all times.

## Themes

The colours of the title bar, status line, prompts, key tags, line numbers, selected text, search matches, error messages and the scrollbar come from a theme file per Zacess theme in [`terminal/nano/themes`](../../terminal/nano/), generated by [`build-themes.py`](../../terminal/terminal/scripts/build-themes.py) from the palette. The `nanorc` includes `~/.config/nano/zacess-theme.nanorc` and `zt` links the current theme's file there on every switch, so `zt deep-dark` reaches nano as it reaches tmux and btop. nano reads its files at start, so an open nano keeps its colours until it is reopened. `zt current` and `zt doctor` list nano and `zt pin nano <theme>` keeps it on one theme while the rest follow `zt`. Syntax highlighting uses nano's own definitions, which name the terminal's colours, so it follows the palette the terminal is on.

## Install

| System | nano | The config |
| --- | --- | --- |
| macOS | `brew install nano` (in [`shell/mac/Brewfile`](../../shell/mac/Brewfile)). Apple's `/usr/bin/nano` is Pico 5.09, which reads no configuration file at all | `~/.config/nano/nanorc`, linked by [`setup/mac-bootstrap`](../../setup/mac-bootstrap/) once Homebrew's nano is there |
| Linux and WSL | Packaged on Ubuntu and Fedora | `~/.config/nano/nanorc`, linked by the `configs` extra of [`setup/linux-bootstrap`](../../setup/linux-bootstrap/) |
| Windows | The nano inside Git for Windows, run from Git Bash | `%USERPROFILE%\.nanorc`, linked by [`setup/windows-bootstrap`](../../setup/windows-bootstrap/) |

nano reads `~/.nanorc` first and only then `~/.config/nano/nanorc`, so a stray `~/.nanorc` on a Mac or Linux machine would hide this one. Homebrew puts its nano before Apple's on `PATH`, so a plain `nano` is the GNU one once it is installed.

## Check it worked

1. `nano --version` says GNU nano, not Pico.
2. Open a file. Line numbers show on the left, the title bar is in the theme's accent colour and the cursor position is on the status line.
3. Type, then `Ctrl+Z` undoes it and `Ctrl+Y` puts it back. `Ctrl+S` saves without a prompt. `Ctrl+Q` leaves.
4. `zt current` lists nano on the theme `zt` last set.

## Validation

`build-themes.py --check` runs in CI and fails when a committed theme file is out of date or any text colour in a theme, measured as nano shows it, falls under 4.5:1. The `nanorc` itself is kept to nano 6.0's options and key names by hand.
