# Accessibility

What the OneDrive setup changes on screen.

- **One tray icon, always shown.** OneDrive's icon sits beside the clock rather than behind the tray's arrow, so its sync state is in the same place every time, as on Windows.
- **No window at login.** OneDriveGUI starts minimised to the tray, so nothing opens over other windows when the desktop starts.
- **A keyboard-only setup.** Every step in the README is a terminal command apart from the browser sign-in, which is Microsoft's own page.
