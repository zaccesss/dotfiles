# apps

Desktop apps that shape how I move around the Mac: a launcher and a window manager, both driven
from the keyboard with one consistent modifier pair. Two more carry the Zacess themes on every
platform: a notes app and a reference manager.

| Folder | What it is | Platforms |
| --- | --- | --- |
| [raycast](raycast) | An extension list and a recommended hotkey scheme, with setup and reference guides | macOS |
| [rectangle](rectangle) | An importable `RectangleConfig.json` with default and custom shortcuts and a full shortcut reference | macOS |
| [obsidian](obsidian) | The Zacess theme installed in a vault, the variant picked through Style Settings and that vault opened by default | macOS, Linux and Windows |
| [zotero](zotero) | Zotero's dark or light mode and reader theme matched to the Zacess theme, plus larger text | macOS, Linux and Windows |
| [onedrive](onedrive) | A personal OneDrive synced in full into `~/OneDrive` by the OneDrive client, with OneDriveGUI's tray icon | Linux |
| [translucenttb](translucenttb) | A dark acrylic taskbar that turns solid with a maximised window or battery saver | Windows |
