# Extensions

What each extension in [extensions.txt](../extensions.txt) does.

## Spotify Player

Author: mattisssa. Media control for Spotify without switching apps: play and pause, next and
previous, volume steps, like and dislike, shuffle and repeat, queue, device switching, playlist
actions, lyrics and a menu-bar now-playing command. It ships far more commands than are bound to a
hotkey, see [hotkeys.md](../hotkeys.md#recommended-spotify-player) for the ones worth a shortcut.

## Kill Process

Author: rolandleth. Search and force-quit a running process by name, faster than opening Activity
Monitor for a single hung app.

## Google Chrome

Author: Codely. Search open tabs, browsing history and bookmarks from Raycast directly rather than
switching to Chrome first.

## Slack

Author: mommertf. Search channels, DMs and unread messages, then jump straight to one without
switching to the Slack app first.

## Worth considering

Real Store extensions that reach inside an app instead of only opening it:

| Extension | Author | Slug | What it adds |
| --- | --- | --- | --- |
| GitHub | raycast | `github` | Issues and pull requests from Raycast |
| Linear | linear | `linear` | Search and create issues |
| Notion | notion | `notion` | Search and open pages |
| Zoom | raycast | `zoom` | Start, join and schedule meetings |
| Docker | priithaamer | `docker` | Manage containers without opening the app |

Install any of them by searching its slug in Raycast's Store tab.
