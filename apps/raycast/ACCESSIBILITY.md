# Accessibility

The hotkey scheme is designed to be learnt once and reused everywhere.

> [!NOTE]
> Some of these settings are preferences rather than requirements. Change them freely in your own copy. If a change would help other people too, open an issue or a pull request so I can consider it for everyone.

## Keyboard and memory

- One global shortcut, `Option+Space`, opens Raycast from anywhere and reaches every command.
- Every recommended extension shortcut uses the same pair, `Option+Control`, with each letter used once, so one pattern covers them all.
- Application Quicklinks belong on a different pair such as `Command+Control`, so the two kinds of shortcut never collide.
- Spotify playback and volume work from anywhere without switching apps.

> [!WARNING]
> VoiceOver uses Control+Option as its own modifier, the VO keys, so with VoiceOver running the extension shortcuts on that pair collide with VoiceOver commands. Put the extension pair on Command+Control instead. Another fix is setting the VoiceOver modifier to Caps Lock in VoiceOver Utility.

## Reading the shortcuts

[hotkeys.md](hotkeys.md) joins every key in a shortcut with `+`, so it is never unclear how many keys are held at once. A legend explains each modifier symbol, including the Control symbol that is easy to confuse with a caret.
